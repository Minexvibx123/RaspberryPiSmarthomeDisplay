# App: Energie

Eigenständige Vollbild-Ansicht des Home-Assistant-Energiedashboards. Die App
verwendet dasselbe Energy-Dashboard-Widget wie das Dashboard und bietet die
Zeiträume Heute, 7 Tage und Monat.

Voraussetzung: Home Assistant ist verbunden und das Energiedashboard enthält
Quellen mit aufgezeichneten Langzeitstatistiken.
